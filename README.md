# بداية الهداية

An Arabic web app for the seven daily reading routines in [ورد.md](ورد.md), with prayer times for Cairo.

[Open the app](https://moabdelmoez.github.io/awrad-elyoum/)

See the [reader README](site/README.md) for local build and iPhone installation instructions. GitHub Pages rebuilds and publishes the app on pushes to `main`.
